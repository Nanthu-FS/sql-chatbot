Atlas

Knowledge Graph Builder  ·  LangGraph  ·  Ollama  ·  FastAPI  ·  Chroma

Input
Text Ingestion
Paste any raw text — articles, research papers, meeting notes, or domain documents. Multi-file input supported.
raw text
Node 1  ·  Local LLM
Triple Extraction via Ollama
The LLM reads the text and extracts structured semantic triples — fully offline, no API keys required.

Output format:  (Entity) ──[relation]──> (Entity)

Examples:
"Elon Musk" ──[founded]──> "Tesla"
"Tesla"     ──[produces]─> "Model S"
"SpaceX"   ──[launched]──> "Falcon 9"
llama3.2:3b JSON structured output 100% local
entity-relation triples
Node 2  ·  Graph Store
Entity Normaliser + Custom Graph
Incoming triples are deduplicated and merged in real-time. Similar entity names are resolved to a canonical form. The graph is persisted using a dependency-free custom store — no external graph database required. Custom BFS traversal is implemented directly.
deduplication entity merging BFS traversal file persistence
Semantic Layer
Chroma Vector Store
Entity names and descriptions are embedded using nomic-embed-text via Ollama and stored in Chroma. Enables fuzzy entity resolution and semantic search when the user types a query.
nomic-embed-text Chroma DB
Visual Layer
Force-Directed Canvas UI
Nodes rendered on a custom HTML5 canvas with physics simulation. Supports drag, zoom, and pan. Node colour indicates entity type.
Person Org Place Concept Event Product
User Input
Natural Language Query
User types a question such as "How is X connected to Y?". The query is passed to a LangGraph agent that resolves entities and finds the relationship path in the graph.
query string
LangGraph Agent  ·  4-node state machine
1
Detect Intent Classifies the query — path lookup, factual question, or open exploration — to route to the correct strategy.
2
Resolve Entities Semantic search via Chroma finds the closest matching nodes in the graph for both the source and target concept.
3
BFS Shortest Path Breadth-first traversal through the knowledge graph to find the shortest chain of relationships connecting the two resolved entities.
4
Stream Explanation LLM narrates the discovered path in natural language. The canvas simultaneously animates the relationship chain with highlighted edges.
